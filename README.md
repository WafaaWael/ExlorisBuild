# Exloris 2 — Unity Educational Game

**Unity Developer | C# | Unity 6 | URP | 2D Gameplay | Localization**

Developed an interactive Unity educational game set in ancient Egypt, featuring player avatar selection, map navigation, a three-lane boat challenge, and a Nilometer-based learning quiz. Built gameplay systems, UI flows, audio feedback, save data, and multilingual support for an engaging child-friendly experience.

## Key systems and achievements

- Built a 2D boat gameplay system with lane-based movement, keyboard/touch input, obstacles, coin collection, progress tracking, scoring, stars, and completion flow.
- Developed a Nilometer learning activity with animated water levels, narrated dialogue, multiple-choice questions, hints, answer validation, star-based feedback, lessons, and completion screens.
- Implemented event-driven architecture in C# using a typed event bus to decouple gameplay, UI, visual effects, and audio systems.
- Created responsive UI for menus, avatar selection, tutorials, HUD, settings, pause states, dialogue, and level completion.
- Integrated DOTween for UI, water, camera, and gameplay animations.
- Added music, ambience, voice-over, sound effects, mixer volume controls, music ducking, and pause-aware playback.
- Implemented encrypted player save/load using JSON serialization, AES encryption, and HMAC integrity validation.
- Added English and Arabic localization support with RTL TextMeshPro compatibility.
- Configured Unity scenes, URP assets, prefabs, visual effects, shaders, and WebGL project resources.
